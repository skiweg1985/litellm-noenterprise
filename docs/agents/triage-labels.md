# Triage labels

Canonical roles map directly to these GitHub labels:

| Role / label | Meaning |
| --- | --- |
| needs-triage | Maintainer needs to evaluate the issue |
| needs-info | Waiting for more information |
| ready-for-agent | Fully specified and ready for an autonomous agent |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |

Use these exact strings when applying triage roles.
