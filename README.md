# litellm-noenterprise

## Purpose

Build our own LiteLLM version with independently developed alternatives
to enterprise features.

## Status

Repository setup is complete. LiteLLM source code has not been imported;
no custom features are implemented yet.

## Next

1. Prioritize the enterprise features we need alternatives for.
2. Select an upstream LiteLLM version and define the integration approach.
3. Implement the first alternative.
